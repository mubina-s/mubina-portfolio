# Mubina Sadriddinova — Portfolio

A black + hot-pink cybersecurity engineering portfolio built as a static site for GitHub Pages.

## Features

- Responsive recruiter-facing single-page design
- Home, About, Experience, Study Cases, Projects, Skills, References, Blog, Goals, and Contact navigation
- Featured software and embedded systems projects
- Curated cybersecurity, software, Linux, and hardware study areas
- Cybercrime/security blog notes and personal interests
- Professional and personal goals
- Screenshot-inspired two-column contact form that opens the visitor's email app with a pre-filled message
- Closing “Thanks for scrolling” panel
- Built-in portfolio Q&A
- Optional free local AI semantic search running in the browser with Transformers.js
- No paid hosting, paid AI API, or API key required

## Deployment

The site is static. Upload the contents of this folder to your GitHub Pages repository and publish from the branch/folder you normally use for GitHub Pages.
